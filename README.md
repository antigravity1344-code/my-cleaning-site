# 🧼 سامانه خدمات نظافت «پاک‌شو» (PakSho Cleaning Platform)

پروژه وب‌اپلیکیشن جامع خدمات نظافت منزل، محل کار، مبل‌شویی، راه‌پله و خانه‌تکانی با React 19، TypeScript و Tailwind CSS 4.

## 🚀 راهنمای راه‌اندازی و اجرای محلی (Local Setup)

### پیش‌نیازها:
- **Node.js** نسخه ۱۸ یا بالاتر (دانلود از nodejs.org)
- **npm** (همراه با Node.js نصب است)

---

### مراحل اجرا در ۳ گام ساده:

1. **استخراج فایل فشرده:**
   فایل زیپ دانلود شده را در یک پوشه دلخواه اکسترکت (Extract) کنید.

2. **نصب وابستگی‌ها (Install Dependencies):**
   یک ترمینال (Command Prompt یا PowerShell یا Terminal) در پوشه پروژه باز کنید و دستور زیر را اجرا نمایید:
   ```bash
   npm install
   ```

3. **اجرای سرور توسعه (Dev Server):**
   ```bash
   npm run dev
   ```

4. **مشاهده وب‌سایت:**
   مرورگر خود را باز کرده و به آدرس زیر بروید:
   `http://localhost:3000`

---

### 📦 دستور بیلد نهایی برای هاست یا سرور (Production Build):
```bash
npm run build
```
فایل‌های خروجی در پوشه `dist` قرار می‌گیرند و آماده آپلود روی هر هاستی هستند.

## توسعهٔ MVP عملیاتی

نسخهٔ فعلی رابط کاربری می‌تواند در دو حالت اجرا شود:

- **حالت دمو (پیش‌فرض):** سفارش‌ها در مرورگر ذخیره می‌شوند تا جریان رزرو بدون بک‌اند قابل بررسی باشد.
- **حالت API:** برای اتصال به بک‌اند، یک فایل `.env.local` بسازید و نشانی API را وارد کنید:

  ```bash
  VITE_API_BASE_URL=https://api.paksho.ir
  ```

  پس از تغییر متغیر محیطی، سرور توسعه را دوباره اجرا کنید.

### قرارداد API سفارش‌ها

در حالت API، رابط کاربری این endpointها را فراخوانی می‌کند. پاسخ‌های موفق باید مستقیماً یک شیء سفارش یا آرایه‌ای از سفارش‌ها باشند.

| Method | Endpoint | کاربرد |
| --- | --- | --- |
| `GET` | `/orders` | فهرست سفارش‌های کاربر واردشده |
| `GET` | `/orders/:id` | دریافت یک سفارش |
| `GET` | `/orders/tracking/:trackingCode` | پیگیری با کد سفارش |
| `POST` | `/orders` | ایجاد سفارش جدید |
| `PATCH` | `/orders/:id/status` | به‌روزرسانی وضعیت یا امتیاز |

API باید احراز هویت، اعتبارسنجی شمارهٔ موبایل و بررسی مجوز نقش‌ها را در سرور انجام دهد. نتیجهٔ پرداخت نیز فقط پس از تأیید callback در بک‌اند معتبر است.
