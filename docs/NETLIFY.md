# استقرار روی Netlify

## تنظیمات پروژه
- این پروژه یک سایت جدا در Netlify است؛ با سایت ادبی تداخلی ندارد.
- فرمان ساخت و پوشهٔ خروجی در `netlify.toml` تعریف شده‌اند (`npm run build` و `dist`).

## متغیر محیطی (در Netlify → Site configuration → Environment variables)
- `VITE_PAKSHO_API_BASE`: آدرس سرور پاکشو، مثلاً `https://<آدرس-سرور>`.
  بدون این متغیر سایت در حالت نمایشی می‌ماند.

## نکتهٔ حتمی روی سرور پاکشو
دامنهٔ سایت Netlify (مثلاً `https://<نام-سایت>.netlify.app`) باید در `corsOrigins` سرور پاکشو باشد. وگرنه مرورگر درخواست‌های قیمت، کد پیامکی و ثبت سفارش را رد می‌کند.

## مسیر پیگیری
- `/track` با `netlify.toml` به `index.html` برمی‌گردد و صفحهٔ پیگیری مستقیم باز می‌شود.

## بررسی بعد از استقرار
1. صفحهٔ اصلی باز شود.
2. `/track` مستقیم باز شود (نه فقط از داخل سایت).
3. در فرم رزرو قیمت از سرور گرفته شود (نه قیمت نمایشی).
