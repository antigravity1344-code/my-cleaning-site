### Build و تطبیق فایل‌ها
- Build موفق بود (`VITE_PAKSHO_API_BASE=https://pakshu.ir`).
- فایل‌های JS و CSS منتشرشده با خروجی محلی `dist` از نظر SHA256 یکسان بودند.
- فایل قدیمی JS طبق دستور حذف نشد و کنار نسخهٔ جدید باقی ماند.

### آزمایش پس از انتشار (بدون Restart)
- سایت اصلی (`https://pakshu.ir`): HTTP 200
- مسیر `/track`: HTTP 200
- API اصلی مورد آزمایش: HTTP 200
- کد رهگیری ناموجود: پاسخ 404 موردانتظار
- حالت DEMO خاموش است
- سرویس‌های PM2 و Nginx Restart نشدند
